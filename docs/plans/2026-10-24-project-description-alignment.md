# Project description alignment and reveal

The three mobile projects had independently flowing text columns. Different title lengths, summary wrapping and Sige's prototype disclosure shifted contributions, metadata and case-study links onto different baselines.

Keep the existing portfolio direction, typography and app footage. Use a shared seven-row grid for media, title, overview, contribution, role, technology list and case-study link at widths above 1000px. Nested subgrids let each row grow to its longest content without fixed text heights or truncation. Group the summary and optional prototype disclosure into one overview. Use consistent 16px spacing throughout all five project descriptions, with 12px shared desktop row gaps. Tablet side-by-side and mobile stacked layouts use natural content flow.

Each complete description block and preview now has a short 12px entrance over 560ms, with a 70ms stagger between mobile-project columns. Text rows move together and settle into the shared grid. The reveal runs once, leaves content visible without JavaScript, and cancels for reduced motion. Review identified a delay-time visibility flash; applying `fill: backwards` fixes it without persisting an animation style after completion.
