# Agents on the actual homepage

The user's revised direction places the three decorative agents directly on the
existing homepage. Remove the separate intro dialog, miniature portfolio, welcome
finale, session gate and Skip control. Content and links are immediately available.

Render a hidden, aria-hidden, pointer-transparent layer with Design, Content and
Frontend cursors. The latest direction extends these collaborators through the
whole homepage, including every project, toolkit, about, contact and footer.
Use routes across visible previews/headings/actions with content reveal effects,
selection outlines, click rings and completion checkmarks. Finish each screenful
before gradually scrolling to the next. The homepage stays usable throughout.

Keep decoration inside the viewport. Provide accessible Pause/Resume and Stop
tour controls. Resume only effects suspended while running so completed reveals
stay finished. User wheel/touch scrolling, page links, keyboard navigation,
resize, Escape, tab hide, page exit or a motion preference change stop the tour.
Bypass for reduced motion, deep links and history restoration; no JavaScript
leaves decoration hidden. Content is never locked, duplicated or replaced.

Implementation and validation are recorded in
2026-11-03-full-page-agent-tour.md. Browser script: tmp/check-home-agents.mjs.
