# Credential issuer icons

Google, DataCamp and Codecademy SVGs are from [Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons).
IBM artwork is the issuer logo displayed on [Jayrald's IBM Coursera credential](https://www.coursera.org/account/accomplishments/verify/CCLGM0NVP0SH).
Simple Icons artwork is released under CC0-1.0. Brand names and marks belong to their respective owners.

The site embeds these local files at build time so credentials do not depend on third-party image requests.
