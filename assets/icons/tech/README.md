# Tech stack icons

Locally bundled plain SVG marks from [Devicon](https://github.com/devicons/devicon), downloaded 2026-10-23. See LICENSE for the MIT copyright and permission notice. Product marks belong to their respective owners.

Each file is an unmodified copy of `icons/<name>/<name>-plain.svg` in the Devicon repository:

- typescript.svg
- dart.svg
- python.svg
- angular.svg
- django.svg
- flutter.svg
- fastapi.svg

The portfolio displays these vector silhouettes using CSS masks so they remain legible in both themes. Django's mark identifies the Django REST Framework work in SkyFire. The accessible link names and focus/hover labels identify every technology, and each link opens an existing local case study. No runtime icon CDN is needed.
